# Basic Parsing

The repository root directory contains the executable JAR file:

`basic_parsing.jar`

To run the .jar application, execute it in a terminal with an argument for the path o the dataset

```bash
java -jar basic_parsing.jar "path"
```

Where:

- `path` is the path to a directory containing the dataset.
- The dataset files must be **decompressed** before running the application.
